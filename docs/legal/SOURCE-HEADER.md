# StygNox Source File Licence Header

For normal StygNox source files, the minimal recommended machine-readable header is:

```text
SPDX-License-Identifier: AGPL-3.0-only
```

Where a copyright notice is appropriate, identify the actual copyright holder rather than treating "StygNox" as a legal entity unless it has become one.

Example:

```text
Copyright (C) <year> <copyright holder>
SPDX-License-Identifier: AGPL-3.0-only
```

Do not replace the full repository `LICENSE` with this header; the repository should retain a complete copy of the AGPL licence text.
