# StygNox Gemini Instructions

Use `AGENTS.md` as the authoritative repository-level operating policy.

Project-local engineering skills are under `.agents/skills/`, with catalogue and routing guidance in:
- `docs/agent-skills.md`
- `docs/agent-skill-routing.md`

Before specialised work, select the smallest relevant set of skills and read their `SKILL.md` files.

Skills do not broaden task authority or override StygNox human gates, controller authority, test policy, or evidence requirements.

Apply `verification-before-completion` before claiming that work is complete, fixed, passing, or ready.
