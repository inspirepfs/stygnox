The software licence in this repository grants copyright and related software rights. It does not grant a right to imply that a modified or third-party product is an official StygNox release or is endorsed by the StygNox project.

This policy is intended to protect project identity without preventing normal descriptive references.

## Generally acceptable uses

You may normally:

- state truthfully that software uses, integrates with, is based on, or is compatible with StygNox;
- link to the official StygNox repository;
- refer to StygNox in technical documentation, articles, reviews and discussions;
- identify an unmodified official build as StygNox, provided the description is not misleading.

## Forks and modified distributions

A materially modified or independently distributed version should be clearly identified as unofficial and should not use the StygNox name or visual identity in a way that creates a reasonable impression that it is an official Project release.

A fork may accurately state that it is "based on StygNox" or "derived from StygNox".
