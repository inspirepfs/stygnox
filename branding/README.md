# StygNox Development Style Guide v1.0

A developer-ready design system derived from the approved StygNox branding direction.

## Start here

Open:

- `style-guide.html` — visual design system
- `homepage.html` — responsive reference homepage
- `docs/STYLE_GUIDE.md` — implementation rules and rationale

## Development files

- `design-tokens.json` — framework-neutral token source
- `css/design-tokens.css` — CSS custom properties
- `css/components.css` — baseline components
- `assets/brand/` — selected StygNox identity assets
- `assets/ascii/` — plain and ANSI-coloured text art

The HTML examples are dependency-free and can be used directly or translated into React/Vue/Svelte components.
